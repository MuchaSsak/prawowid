# 010: the product is called Prawdomat (display name only)
Date: 2026-11-21 · Status: decided
Context: "PRAWDOWID" is the name of the MSZ hackathon task, so every team on it shares that name. We wanted a name of our own that is short, catchy and plain Polish for citizens with low digital skills.
Decision: the product's **display name** is **Prawdomat**: UI text, bot replies, page titles, log lines, READMEs and wiki prose. **Technical identifiers keep "prawdowid"** so nothing breaks: env vars `PRAWDOWID_*`, packages `@prawdowid/*`, cookies, the User-Agent `PrawdowidBot/` and its robots.txt match, the bot `userName`, the MCP `clientInfo`, the Supabase `project_id`, the deployed host `prawowid.mateusz.deno.net`. LLM prompt text is unchanged as well, so prompt versions and eval results stay comparable. "PRAWDOWID" also stays wherever it means the MSZ task (`hackathon/`, the Discord channel and MSZ booth names).
Rejected: renaming identifiers too (user: don't break deployed configs); keeping "Prawdowid" (shared with every team); Dowodnik, Fakt czy fejk, Czy to prawda? and others from the brainstorm (user's choice). The EU trademark check (TMview, EUIPO eSearch) could not be done automatically, because both blocked automated requests. A web search found no trademark or app named "Prawdomat". Confirm by hand (see open-questions).
Affects: UI and bot copy in apps/, [architecture/](../architecture/README.md) prose, [pitch/jury-insights.md](../pitch/jury-insights.md).
