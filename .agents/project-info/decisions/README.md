# Decisions

Settled choices and the reasons for them. Read these before proposing changes, and don't re-argue a decision unless there is new information.

**Format:** one file per decision, `NNN-slug.md` (e.g. `001-tech-stack.md`):

```
# NNN: <decision>
Date: YYYY-MM-DD · Status: decided | superseded by NNN
Context: why it came up
Decision: what we chose
Rejected: the alternatives, and why not
Affects: links to the pages updated because of it
```
