# 013: Operator source controls on the BM25 corpus, not the PR #13 registry
Date: 2026-11-22 · Status: decided (user asked for a faster corpus with all data and "możliwość kontroli źródeł"; the design below is the agent's)

Context: PR #13 (`t3/test-source-registry`, stacked on #12) built a full source registry (publishers, bindings, eligibility, versioned documents, `/admin/zrodla`) on top of pgvector and a Python retrieval service. Ten minutes after it was finished, `main` replaced that whole layer with an in-process BM25 index (`IndexedCorpusStore`, 31 collector collections). Merging gave 15 conflicted files, most of them "deleted on main, changed in the PR". The final deadline is Sun 22.11, 11:00 ([event-and-jury](../hackathon/event-and-jury.md)). At the same time the BM25 search took ~2.4 s per query, because it rebuilt the index on every call.

Decision:
- **Keep BM25, drop pgvector.** No Docker or Python service; it runs on Deno Deploy. Search fixed to use the index built at load time: same top-5 results on 8 of 8 real queries, about 2145 ms → 29 ms per search (Bun, local, 47k fragments). Filters (operator switches, tiers, dates) run during ranking instead of rebuilding an index.
- **Switches, not a registry.** Three kinds of key, all on or off, nothing else editable: `route:<connector>` (Google Fact Check, Sejm ELI, Eurostat, NBP, GUS, the corpus), `corpus:<collection>` (one collector collection, e.g. `corpus:demagog`), `publisher:<catalog id>` (an allowlist publisher, on every route, by citation URL host). Code: `packages/core/src/sources/controls.ts` (`applySourceControls`, pure), API `apps/api/source-controls.ts`.
- **Semantics.** A switched-off source never becomes evidence and leaves `GET /api/v1/sources`. A switched-off required route turns its claims into `source_unavailable` with "wyłączone przez administratora", never a verdict (hard constraint 8). An optional one shows as `skipped` and does not lower verdict strength (it is the deployment's choice, not a missing database). A publisher is resolved by the most specific catalog domain (`publisherOf`: `isap.sejm.gov.pl` is Sejm, not gov.pl). Connectors run with the full catalog (Google Fact Check filters by the allowlist itself), and the switch layer decides: when every record a required route found is from a switched-off publisher, the route reports `unavailable` ("wyłączone przez administratora"), so the claim gets a system state; an optional route (the corpus too) just reports `no_hits`, because retrieve() treats a failed corpus like a required failure and would discard other routes' evidence. `route:corpus` off swaps in an empty corpus for every reader, including the reference-date lookup. (Edge cases found by a Fable review, fixed 2026-11-22.)
- **Pinned per check.** The state is read once when a check starts. Its revision is part of the result cache key, so an answer cached before a change is never served after it. If the state can't be read within 2 s, the check fails closed (`technical_error`) and `GET /api/v1/sources` answers 503, never with every source on. A switched-off key whose source has disappeared (rebuilt corpus) can still be switched back on.
- **Storage.** Deno KV when the runtime has it (shared by instances, survives restarts), else memory for that instance only. The admin page says which one is in use. Audit: last 50 changes (time, key, on/off).
- **Auth.** The existing `ADMIN_TOKEN` and admin login guard ([decision 011](011-admin-analytics.md)). No unauthenticated operator header, unlike PR #13.

Rejected:
- **Merging PR #13 as is:** it rebuilds the layer `main` removed, needs Docker, and its operator name is an unauthenticated header.
- **Porting the full registry** (bindings, RSS/WordPress adapters, versioned documents): several hours of risk right before the deadline. It can come back after the event on top of `applySourceControls`.
- **pgvector for speed:** at our size, BM25 with an inverted index is already in milliseconds, and the LLM dominates end-to-end latency. The real case for vectors is recall on paraphrases (hybrid search, [Pavel review](../architecture/pavel-proposal-review.md)), not speed.

Affects: [codebase](../architecture/codebase.md), [api-reference](../architecture/api-reference.md), [decision 008](008-trusted-source-allowlist.md) (the allowlist can now shrink at runtime), [open-questions](../open-questions.md).
