# 012: Bulk ingestion of the organizer's sources: 12 months, full texts, Python on the user's laptop
Date: 2026-11-21 · Status: decided (user's answers; tool choice is the agent's)

Context: the user wants all data from the organizer's source list ([resources.md](../hackathon/resources.md#discord-message-user-2026-11-21)) pulled into our corpus within at most ~15 hours, useful and efficient for the project. Access methods and licenses per source: [data-sources-research.md](../architecture/data-sources-research.md). The active corpus pipeline is JSON/JSONL → `scripts/convert_alert_data.ts` + `scripts/build_corpus_index.ts` → an in-process BM25 index read by `IndexedCorpusStore`.

Decision:
- **Where (user, 2026-11-21, later the same day):** collectors live in Pavel's repo https://github.com/PavelSfk/Data (`alert_collector` package: `requests` + `beautifulsoup4`, one `Record` model, `JsonStore` writing `data/<source>.json`, one `scripts/collect_<source>.py` and one test per source; progress tracked in its `LINKS_STATUS.md`). That repo's stack and conventions win over the tool list below, with no periodic recording of any source: an hourly/15-min state history for IMGW and RSO was built and then **removed at the user's request (2026-11-22)**; IMGW comes instead from the historical archive on danepubliczne.imgw.pl (6 months): hydrological warnings (`/data/arch/ost_hydro`, 1612 records incl. 137 coastal ones for Bałtyk) and the monthly PSHM bulletins. **No meteorological data is collected** (no meteo warnings, no measurements, no marine weather warnings; user, 2026-11-22). Work split: another person goes down `LINKS_STATUS.md` from the top; we go up from the bottom (Kancelaria Premiera, then Dyplomacja, ...); Google Fact Check last. Local work only, no push until the user says so.
- **Local import (user, 2026-11-22):** a snapshot from `PavelSfk/Data` was copied into the main repo as `data/raw/*.json` and `tools/collector/{alert_collector,scripts,README.md}`. The JSON files are intentionally local because the main repo's `.gitignore` ignores `/data/`; the copied collector files are available for jury inspection and future ingestion.
- **Demagog first (user, 2026-11-21):** demagog.org.pl, 3 years back, goes before Kancelaria Premiera. It is the corpus's secondary (fact-checker) source type and an extra domain, so the brief's "≥2 source types" no longer waits on the Google Fact Check key. Adapter: `alert_collector/demagog.py` in the Data repo (its own file to avoid conflicts with the other collector's edits): URLs from the WordPress sitemaps, dates and verdicts from JSON-LD (WebPage `datePublished`, ClaimReview rating, claim, claimant), body as clean paragraphs without the fundraising boxes, 1 request/s, saved every 200 pages. No raw HTML is kept (user: only the text matters, it must be easy to use).
- **Scope:** archives (news, komunikaty, warnings) **6 months back** (user, 2026-11-21, cut from 12 to save time and space). **Exception: Demagog stays at 3 years** (user, 2026-11-21: the fact-checker archive is needed in full depth); extend further only if time is left.
- **Four kinds of source, four methods:** (A) archives of news and komunikaty: one-time pull of list pages + articles, then incremental; (B) live state (IMGW, GIOŚ, PAA monitoring, GDDKiA lista utrudnień, RSO, gov.pl/ostrzezenia): no periodic snapshots (user, 2026-11-22); live state is read at check time by connectors, and history comes from the sources' own archives where they exist; (C) static info pages (passenger rights, hotlines, contacts): one pull, daily refresh; (D) JS apps: use the JSON API the page itself calls. Odyseusz has one (`https://odyseusz.gov.pl/api/v1/informacje/profile-panstw`, `/strona-glowna/baner-sytuacje-kryzysowe`; seen in the browser 2026-11-21; no robots.txt), so no browser rendering is needed there.
- **Adapters per platform, not per link:** one gov.pl adapter (`?page=N&size=10` lists) covers about 15 of the links; one for the police CMS (policja.pl + regional commands); RSS/API for CERT, IMGW, GIOŚ; Google Fact Check paged per allowlisted publisher (`reviewPublisherSiteFilter`).
- **Full texts are stored** unless a source's terms explicitly forbid it, together with a short corpus archiving policy (legal basis, license per source, retention, access, deletion).
- **Tag stripping (2026-11-22):** the converter strips only real HTML tags (`<\/?[a-zA-Z][^<>]*>`); the old `<[^>]+>` cut real text such as "<50% normy" (IMGW) and "<= 2025.12.5" (CERT).
- **What reaches the corpus (2026-11-22):** 9792 of 10 558 raw records (48 353 indexed fragments). The converter now keeps Cyrillic text, short titles, the full Odyseusz theme pages (flattened `sekcje`/`podsekcje`) and GDDKiA map situations (text composed from road, kind and dates), and `data/raw/policja_rss.json` brings back 14 Policja.pl articles of the old vector corpus (7 more were already in `policja.json`). Left out on purpose: 239 Odyseusz country-profile stubs (name + ISO code; the full profiles are in), link-list pages and footers, 80 UMS PDF links and 2 Wody Polskie notices with a title only, and `gddkia_utrudnienia_raw` (a table dump duplicating `gddkia_obstacles`). **Reworked the same day (user asked to use data/raw better):** 31 934 passages instead of 48 353 single sentences (official median 646 characters, was 125; under 80 characters: 143, was 11 366), split by `packages/core/src/store/passages.ts` (literal slices, offsets verified on all 14 756 official passages); Demagog keeps each verdict card in the Google Fact Check passage shape (claim, claimant, claim date, rating, title: 3 132) plus the first 4 article passages labelled "Fragment artykułu weryfikacji:" (14 046; 11.7 M of 22.4 M characters, was 0.48 M), so the assessment sees the fact-checker's findings; the publisher comes from `raw.publisher` or a per-source name (no more 27 k "gov.pl"); `origin_key` = `publisher:<slug>` (decision 008: one publisher counts once; was the URL); `retrieved_at` = the record's `last_seen_at` (was the build time); records with a validity period start with "Obowiązuje od … do …" and live-state snapshots (GDDKiA map/obstacles, RSO, PAA monitoring, GIOŚ) with "Stan na … (dane bieżące w chwili pobrania)" (3 072 passages); duplicates read from both `../data` and `data/raw` are dropped. Index file 38.7 MB (compact JSON, was 41.4 MB); `alert-corpus.jsonl` 39 MB (full Demagog bodies, was 14 MB); load ~4.3 s on the laptop.
- **Runs locally** from the repository snapshot: the TypeScript conversion/build scripts produce `data/corpus/alert-corpus.jsonl` and `data/corpus/alert-corpus-index.json`.
- **Python 3.12** in a project `.venv`: `httpx` (async, per-host rate limit ~1 request/s, honest User-Agent), `selectolax` for list pages, `trafilatura` for article text and publication date across ~20 different site layouts, `feedparser` for RSS. Same language as the existing ingest and embedding code, so one data pipeline. Output: records in the common schema (data-sources-research) as JSONL, raw responses in `data/raw/{source}/`, dedup by URL and content hash.
- **Playwright only as a fallback**, installed when a source proves to have no JSON behind its JS page. Not the default: it is 10-100x slower than the JSON the page calls, heavier on a laptop, and more brittle.
- **Respect robots.txt and terms.** Our crawler feeds an AI fact-checking system, so where robots.txt blocks AI crawlers we treat that rule as applying to us. Consequence for the user's extra sources: **pap.pl** blocks AI crawlers everywhere except `/mediaroom` (robots.txt read 2026-11-21), so only `/mediaroom` may be pulled; **Reuters and AP** stay reachable only through their ClaimReview in Google Fact Check ([decision 008](008-trusted-source-allowlist.md)).
- **Priority if time runs out:** RCB, MSZ/Odyseusz, CERT, police, GIS, fact-checks first; then the other gov.pl units, transport and maritime; GDDKiA and GIOŚ last; then PAP `/mediaroom`; Reuters/AP only via Google Fact Check.
- **Embeddings:** a few hours of CPU time for `multilingual-e5-small` is accepted.

Rejected: one scraper per link (40 scrapers for what is ~6 platforms); Playwright as the main crawler (see above); TypeScript/Deno crawler (no `trafilatura` equivalent, and ingest/embeddings are Python already); scraping PAP, Reuters or AP news pages with a neutral user agent (against their robots/terms, decision 008).
