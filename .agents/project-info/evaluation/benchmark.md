# Tests and benchmark
What is tested, how each metric is computed, the latest results and the known gaps. Results are measured, not estimated. Code: `packages/core/test/`, `apps/api/main_test.ts`, `eval/`.

## Two layers
| Layer | Command | Cost | What it proves |
|---|---|---|---|
| Deterministic tests (156) | `bun run test` | **free**: model and source APIs are stubbed, zero external calls | the rules: no fabricated sources, the source allowlist, abstention, conflicts, the number check, injection, PII never leaves, missing keys, contract v1, HTTP behaviour |
| Live benchmark (50 cases) | `bun run eval` (full, ~$0.05) · `bun run eval:quick` (6 cases, ~$0.005) · `bun run eval:remote` (deployed URL) | real OpenRouter + Google credits | the jury's metrics on real models and sources |
| Statistics smoke test | `deno run --allow-net packages/core/test/live/smoke-stats.ts` | **free** (no model, no keys) | every Eurostat indicator, NBP rates/gold/reference rate and GUS answer live |

Run the full benchmark only before a demo, a submission or a prompt/model change; use `eval:quick` or `--only <ids>` otherwise (user, 2026-11-21: keep credit use low).

### Deterministic tests
- `packages/core/test/pipeline_test.ts` (32): the whole pipeline with a scripted model and scripted sources (`harness.ts` replaces `fetch` and records every outbound call). One test per scenario or release check: A confirm/refute with verbatim citations · rejected invented quotes and invented claims · the model never sees source URLs · C conflict → abstain + `sources_conflict` · D no records → abstain without a 2nd LLM call · D vs J failed source → system state · J missing/rejected key, invalid JSON, 429 → Small fallback · E injection in input, in a source, and **on a page linked from a chat message** · privacy (e-mail, phone, PESEL absent from every outbound request and the log) · opinions → no lookups · inconsistent assessment → abstain · circular corroboration · partial · G cache parity web vs messaging · H never a false "queued" · session deletion · clarification · claim cap · I URL intake, robots.txt, SSRF via DNS, unreadable link in a message → warning · F image OCR, visible date ≠ publication date, vision failure · input rejection.
- `packages/core/test/sources_test.ts` (20): the trusted-source allowlist (look-alike domains rejected, unlisted publishers dropped before the model, tier by credentials, one publisher = one origin, refutation wins a tie with "partly false"); Eurostat (series, EU average and rank in the record, status flags); the number check (wrong number never confirmed, matching number never false, number from another year flagged); Eurostat down → technical state; GUS down → verdict stands with a caveat; NBP (rate in force on a date, 404 = no hits, reference-rate history parser); JSON-stat decoding; period parsing; the prompt's indicator list comes from the catalog.
- `packages/core/test/contract_test.ts` (20): every mock scenario and live outputs validate against the same v1 schema ([decision 006](../decisions/006-api-contract-v1-and-mock.md)).
- `packages/core/test/core_test.ts` (16): PII rules, quote matching, injection patterns, URL guard, EXIF strip, verdict rules, ELI title fragments.
- `packages/core/test/narratives_test.ts` (6): EUvsDisinfo known-incident context: never a citation or model input, verdict unchanged, weak matches and articles dropped, no key / rejected key, our own index takes over from the live search, SSE/JSON/HTML parsing, case mapping.
- `apps/api/main_test.ts` (35): every route including `GET /api/v1/sources`, all 18 mock scenarios over HTTP, missing-key path, malformed bodies, SSRF URLs, 413, rate limits per IP and per bot end user, CORS, 404s.

Rule 16: the set is used only by `eval/run.ts`, never in prompts. Prompt rules added after a run must be general (no case wording); the jury's hidden set will differ.
- C01 gold changed from `insufficient_evidence` to `false` on 2026-11-21: its note said "abstain only because there is no numeric route"; with the routes live, 38,5 mln is false under both the GUS and the Eurostat definition.
- S06 ("stopa referencyjna obecnie 3,75%") is true only while the RPP keeps the rate; re-check the gold after any change.
- C (real conflict) can't be produced reliably from live sources, so the conflict rule is proven by the stubbed test.
- H (moderator loop) is not built: disclosed, and the tests check we never claim "queued".

## Organizer-style set (`eval/organizer-cases.json`)
`deno task eval:organizer` (or `bun run eval:organizer`), 26 cases, ~$0.03, results in `eval/results/latest-organizer.md` and `organizer-<time>.json` (the main `latest.md` is untouched). Added 2026-11-21 (user) to test whether we answer questions *like* the [organizer samples](../hackathon/organizer-sample-answers.md), not only the samples themselves.
- **X01-X08:** the organizer samples A, C, D, E, G, H, J (two J variants: API working and forced failure), each with style checks.
- **R01-R18:** the same patterns on other topics: simple facts as questions and as statements (true and false), old or other-place footage (B), approximations and attribution shifts (C), invented local changes (D, H), "ostatnio" (the Italy-strike pattern), an injected fake assistant turn (E), "Czy Demagog sprawdzał…" with and without the Google key (J), a sweeping accusation (hard constraint 21) and an accusation plus a checkable figure.
- **Gold labels** come from real Demagog ratings found in Google Fact Check Explorer on 2026-11-21 (date and rating in each case's `note`); invented local cases expect abstention. **Assumption:** a human should review them. Ratings can change and the index can drop items, so re-check a failing R case in Fact Check Explorer before blaming the pipeline.
- **`accept`:** B cases count `false` or `misleading` as correct (Demagog rates old footage "Fałsz"; our rules may call it misleading). Both must start with "Nie."/"To nieprawda.".
- **Style checks** (new optional case fields in `eval/run.ts`, reported as "Answer style"): `lead` (the explanation must start with "Tak."/"Nie."/"To prawda."/"To nieprawda.", or `null` = with none of them), `publisher_any` (a citation from Demagog, Eurostat…), `text_includes` / `text_excludes` (e.g. "nie oznacza" in abstentions, never "nie ma takiego artykułu" on a source failure).
- Not covered: F (needs a prepared screenshot), I (needs a post URL that matches a checked item), the H case merge (not built).

## Metric definitions (eval/run.ts)
- **Case prediction:** if the request status is not `ok`/`partial` → `status:<x>` (always wrong; a technical error never counts as an abstention). Otherwise the fact claims' verdicts aggregated worst-first: `false` > `misleading` > `insufficient_evidence` > `confirmed`; no fact claims → `not_verifiable` if an opinion was listed.
- **Macro-F1:** over the 5 verdict classes present in the gold labels.
- **Citation coverage:** decisive verdicts (confirmed/false/misleading) with ≥1 non-context citation. Also reported: fact claims with any citation.
- **Citation correctness:** human labels in `eval/labels/citations.json` (`"<case>|<source_id>|<claim id>": true|false`), filled from `eval/results/citations-review.csv`. Verbatim-in-source is 100% by construction (code rejects other quotes).
- **Abstention:** gold `insufficient_evidence` cases predicted as such.
- **Robustness:** E cases where the attacker's target verdict was not produced, the check completed and `injection_detected` was raised.
- **Latency:** client wall clock, median and p90, uncached text/URL cases. **Cost:** sum of `meta.cost_usd`, scaled to 100 checks.
- **End-to-end:** completed, valid v1 contract, case expectations met. **Channel consistency:** G cases re-sent as `channel: messaging` with another session; verdicts and citation IDs must match.

## Known gaps (ranked by impact on the score)
1. **True claims abstain too often** (confirmed recall 0.50): A08, A10, A11, E03, F02 and S05. In S05 the model labelled the exact NBP line (4,2578 vs claim 4,26) as context. Code never upgrades a stance on purpose (a same-named statistic with another definition must not become a verdict), so the fix belongs in the prompt or the model.
2. **Misleading inference** (B01, B03: true premise + wrong conclusion) still abstains: needs the explicit "misleading inference" handling from pipeline §2.
3. No route yet for news agencies' own text, regional statistics or Sejm votings. Odyseusz country pages are now in the corpus (`corpus:odyseusz:*`). **Organizer sample A (Italian strike), live check of 2026-11-22**, asked as "czy w tym tygodniu we wloszech byl strajk generalny?": the corpus returned Odyseusz/IT (published 2026-11-19), which says the strike "zapowiedziano" for 20 November. The model proposed a yes. The announced-is-not-happened guard (`assess.ts`, `ANNOUNCED`) correctly made that passage context, so the verdict was abstain: no allowlisted source reports that the strike took place. But the code/model disagreement path swapped the explanation for the generic template ("Nie znaleźliśmy wystarczających dowodów…"), and `missing` fell back to the default, so the answer dropped the one fact we had ("zapowiedziany na 20.11 wg Odyseusza, nie wiemy, czy się odbył"). The user read it as "right source, wrong answer". Same run: an `archival_material` warning ("sprzed ponad roku") came from an uncited passage (check.ts reads all passages, not just the cited ones), an unrelated Odyseusz/ES passage was shown as a context citation, and "w tym tygodniu" was not resolved by `dates.ts` (time stayed "ten tydzień"). **Fixed the same day** (branch `t3/fix-italy-strike-verdict`, not yet live): when the guard overrides the model, the abstention now quotes the announcing sentence with publisher and date ("Źródło podaje tylko zapowiedź (…): „…”. Nie znaleźliśmy źródła, które potwierdza, że to się odbyło.") and `missing` says a source published after the date would settle it (`render.ts` `announcementExplanation`); the archival warning reads only cited passages; weeks resolve (below). The ES citation is still shown. Same for fresh news and quotes ("X said Y"): a live onet.pl article of 2026-11-21 on Zelensky and the E5 format gave 5 × `brak wystarczających dowodów` with zero records on every route (routes ran fine, nothing in Fact Check yet, no news route, corpus empty), shown as 5 identical cards.
4. Citation correctness is unmeasured until a human labels `citations-review.csv`.
5. The gold labels are single-annotator.
6. **No reference case covers a known narrative**, so EUvsDisinfo match quality (precision of the "known narrative" note) is not measured by the benchmark; only the live smoke test checked it (2 of 2 matches correct for one query).
7. **`implied_warnings` can turn suspicious**: on that article extraction warned "Zełenski nie przedstawił dowodów, że bez Polski negocjacje nie będą możliwe", demanding evidence for a stated political position (against "fair, not suspicious" in [verification-pipeline](../architecture/verification-pipeline.md)).
