How to connect AI tools for MCP server 

(version 5/05/2026)

! Also you can see video manual (video file attached)








1. https://claude.ai/

	1.1 Use connectors. “One button solution”. Any paid plan required. Unavailable for free plan. 

Open settings







Open connectors







Press the “Add custom connector” button. 




You can use any name. Insert the MCP server URL
https://mcp.euvsd.info/mcp?key=%your_key%




	Where %your_key% is the access token from https://euvsdisinfo.eu/. 
You can generate it here.











Press the “add” button.










If you see a new window again - > close it. Press “cancel” near the “Add” button.




Now you should see your server.







You can configure your server if you press the configure button.







Better to keep “Need approval” for every request if you want to see the query before send.




That’s all. 
Now you can ask Claude:
 “What you can say about the war in Ukraine. Use EuVsDisinfo MCP server.”
